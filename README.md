**Parse, analyse, diagnose and safely post-process wire-laser DED G-code programs**
(SINUMERIK 840D dialect first).

> **Status: pre-alpha (Phase 0 — project setup).** Nothing is usable yet; the API
> below describes the planned v1 scope.

## What it will do

1. **Parse** DED G-code programs (SINUMERIK 840D dialect), streaming, line by line.
   Unrecognised lines are never dropped silently: they raise a warning with the
   line number (or an error in `--strict` mode).
2. **Reconstruct the 3D toolpath** as a table with one row per segment
   (Polars, with exact analytic arc lengths).
3. **Compute process metrics** per segment, pass and layer: deposited length,
   time, energy, wire mass, stepover…
4. **Diagnose process risks** with explainable rules (e.g. layers that are too
   short to cool down).
5. **Apply safe transformations**: insert `G4 F<s>` dwells between layers at the
   line level, then verify the result by re-parsing it.
6. **Report**: interactive 3D view and a self-contained HTML report.

Column names always carry their units (`_mm`, `_s`, `_w`, `_j`, `_mm_min`, `_g`).

## Data and confidentiality

All example and test programs in this repository are **synthetic** (generated by
`dedpath` itself) or built from public geometries. Default parameters are generic
and backed by public references. No proprietary programs, parts, process
parameters or machine data are included.

## Development quickstart

Requires [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/anderbasaras/dedpath.git
cd dedpath
uv sync                      # creates .venv with Python 3.12 + dev tools, installs dedpath (editable)
uv run pre-commit install    # git hooks: ruff, mypy, hygiene checks
uv run pytest                # tests
uv run ruff check .          # lint
uv run mypy src              # strict type checking
uv build                     # sdist + wheel into dist/
```

## Resumen en español

**dedpath** es una librería Python open source (con CLI y demo web) para analizar
programas G-code de **DED hilo-láser** en dialecto **SINUMERIK 840D**: lee el
programa, reconstruye la trayectoria 3D como tabla de segmentos, calcula métricas
de proceso por capa y pasada, diagnostica riesgos con reglas explicables, inserta
esperas `G4` entre capas de forma segura y verificada, y genera un informe HTML
con visor 3D. Todos los programas de ejemplo son sintéticos. Estado actual:
pre-alfa (Fase 0, configuración del proyecto).
